# NICHE DECISION

Selected niche:

PROBLEM-SOLVING GARDENING

This is NOT a generic gardening website.

The core strategy is:

PRODUCT + PROBLEM + USER + ENVIRONMENT

Examples:

best pruning shears for small hands

best soil tester for vegetable garden

best garden tools for raised beds

best trellis for tomatoes

best plant support for tomatoes

---

# WHY THIS NICHE

The decision was based on:

- long-tail keyword potential;
- commercial intent;
- large product ecosystem;
- many possible product/use-case combinations;
- relatively good automation potential;
- ability to create topic clusters;
- seasonal content can be prepared ahead of demand;
- opportunity to target specific gardening problems rather than broad terms.
